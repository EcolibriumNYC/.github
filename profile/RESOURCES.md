# Learning & Development Resources

Guides, required runtimes, and reference material for contributing across our hardware and software repositories.

## Collaboration 
We collaborate and share patches via GitHub pull requests. If you are new to Git workflows, review the [The Odin Project: Git Basics](https://www.theodinproject.com/lessons/foundations-git-basics).

## Tooling & Environment
We standardize toolchains and dependencies via [mise](https://mise.jdx.dev/).
1. Follow the [mise Getting Started Guide](https://mise.jdx.dev/getting-started.html) to install.
2. Run `mise install` in any project root to provision the required runtimes.
